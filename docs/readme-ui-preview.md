## 구현 경계

추가한 화면은 고정 합성 사례의 인터랙티브 UI다. 매출 화면의 업로드 데이터에 적용하는 새 분석 엔진이 아니다.
공식 카탈로그와 구별되는 가상 상품명을 사용한다. 실제 데이터 수집·Supabase·Gemini·직원 인증은 구현하지 않았다.
초안은 시나리오마다 따로 편집·보존·JSON 다운로드할 수 있다. 검토 표시는 탭 내 UI 상태이며 서버 승인·감사 로그가 아니다.
발송·쿠폰 지급·발주 기능은 비활성이다. 성과 표는 사전 정의된 별도 합성 결과이며 이 UI에서 실행된 캠페인의 결과가 아니다.

README는 라온몰 플랫폼 확인 전으로 기록하지만 기존 AGENTS·설계 문서는 Cafe24 확정 기록이 있다.
이번에는 화면에 문서 차이를 표시했으며, 실제 연동 판단이나 기존 확정 기록을 임의로 변경하지 않았다.
