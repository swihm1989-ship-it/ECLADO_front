# README UI 반영 · Ver.1

사용자 요청: 현재 README 두 문서의 승인 범위를 기존 Streamlit UI에 적용한다.
기존 매출 분석 네 화면과 남색/파란색 테마를 유지한다.

접근: 기존 매출 분석을 재작성하는 대신 CRM·마케팅의 누락된 화면을 추가한다.
실제 분석 API가 없는 기능은 연결된 고정 합성 사례의 UI 미리보기로 제공한다.
새 사례는 업로드 데이터에 대한 분석 결과로 표시하지 않는다.

화면: 재주문 추천, 이탈 조기경보, 교차판매, 리뷰 대응·캠페인 초안,
마케팅 성과, 외부 신호·연동 상태. 사례의 기준일·출처·표본·한계를 명시한다.
초안 편집/다운로드와 탭 내 검토 표시를 제공하되 실제 발송·쿠폰·발주는 비활성이다.
Supabase/Auth/Gemini/실데이터 분석 엔진의 구현 완료를 주장하지 않는다.
README의 플랫폼 미확정 표현을 연동 화면에 적용하며 기존 확정 기록과 차이를 명시한다.

검증: Streamlit AppTest로 전체 메뉴, 검토 상태, 초안 유지, 발송 비활성,
기존 매출 메뉴 회귀를 확인한다. pytest/ruff/mypy를 실행한다.
