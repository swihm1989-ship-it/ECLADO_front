# README UI Implementation Plan

**Goal:** 기존 Streamlit UI에 README 2.1–2.10의 검토 동선을 반영한다.
**Architecture:** 기존 매출 화면과 API 경계를 유지하고 새 시나리오 UI를 별도 모듈에 둔다.
**Tech Stack:** Python, Streamlit, pytest AppTest.
**Spec:** ../specs/2026-11-04-readme-ui-design.md

## Constraints
실제 데이터·외부 API·발송 미연결. 합성 사례는 기존 매출 데이터와 분리 표시.
기존 사용자 변경 보존. 커밋/푸시 없음.

## Tasks
- [x] AppTest: 새 메뉴 진입, 시나리오 변경 후 초안 분리 보존, 검토 표시,
  발송 비활성, 매출 메뉴 복귀를 검증하는 테스트를 작성하고 실패 확인.
- [x] `admin/eclado_admin/marketing_pages.py`: 고정 합성 사례와 여섯 화면,
  편집 가능한 초안·다운로드·명시적인 운영 연동 상태 구현.
- [x] `main.py`: 기존 radio 선택값과 호환되는 사이드바 버튼 및 화면 라우팅 추가.
- [x] 테스트 통과 확인, pytest/ruff/mypy 실행, 변경·범위·미연결 항목 문서 기록.

## Verification
현재 체크아웃에서 uv --offline --no-sync로 pytest 40개 통과, Ruff 전체 통과,
mypy 52개 소스 통과. 코드 검토에서 발견한 초안 수정 후 검토 표시 유지 문제를
회귀 테스트 실패 확인 후 수정했다. Windows 임시 폴더 종료 정리 경고는 기존 환경 한계다.
