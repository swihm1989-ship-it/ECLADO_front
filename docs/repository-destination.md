# 저장소 기준 · 2026-11-04

사용자 지시에 따라 작업·커밋·푸시 경로를 `C:\ECLADO_MARKETING_TOOL\ECLADO_front`로 통일한다.
원격은 `https://github.com/swihm1989-ship-it/ECLADO_front.git`, 브랜치는 `main`이다.

기존 작업 폴더에서 Git 추적 파일 103개를 확인했다. 동일한 README 두 개는 보존하고
나머지 소스·테스트·문서·공개 카탈로그·설정을 복사했다. `.git`, `.env`, `.venv`,
로컬 DB·세션·캐시 등 Git 비추적 실행 데이터는 복사하지 않았다.
기존 폴더의 파일과 Git 이력은 보존하며 해당 폴더에서 커밋·푸시를 차단하는 로컬 훅을 설정한다.
기존 원격에 이미 있는 커밋은 삭제·변경하지 않는다.

이 작업은 파일 배치와 로컬 Git 설정 변경이다. 커밋·푸시는 별도 실행하지 않았다.

새 경로의 독립 Python 3.14 가상환경에서 pytest 40개, Ruff, mypy 52개 파일 검사를 통과했다.
기존 서버 프로세스만 종료하고 새 경로에서 백엔드(8000)·Streamlit(8501)을 다시 실행했다.
로컬 업로드 데이터와 기존 데모 세션은 복사하지 않았으므로 재로그인·가상 데이터 재연결이 필요할 수 있다.
이전 저장소의 훅은 실제 커밋·푸시 없이 `git hook run`으로 각각 종료 코드 1을 확인했다.
